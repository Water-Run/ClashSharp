# 设置组的完整重置

设置页的基础、通知、触发器、托盘、Windows 代理策略和地区设置此前逐项写入。
例如基础组在写入语言后就更新显示，再保存主题、主题色及关闭行为。其他独占
操作可以在两项写入之间关闭准入，后续写入被拒绝时，前面的值已经生效。

现在这六组通过 `ISettingsStore.ResetPreferenceGroup` 提交一次重置。适配器将
请求交给现有 `AppSettingsService`，后者根据设置注册表选择该组的规范键和旧键，
在同一个普通写入许可内提交完整批次。编辑器只接受服务拥有的键；地区设置同时
移除旧显示开关，避免读取旧键时覆盖已恢复的默认值。

批次复用现有提交与进程内回滚机制，全部写入完成后才通知观察者，通知期间仍持有
许可。ViewModel 在存储成功后先更新整组字段，再发出属性和重启提示通知。存储
失败时，显示值保持不变；基础组的主题回调在完整状态发布后执行一次。

这里的注册表只提供键及组关系，生产存储仍是 LocalSettings。启动项、TUN、混合
端口和连接采样需要对应的运行时协调，本接口拒绝这些作用域、组合值和全量重置。
本变更不表示完整设置文件代际迁移已经完成，也不将进程内回滚声明为断电原子性。

页面保存失败及基础组完整显示通知。验证同时确认其他组及网络/启动参数保持，
地区旧键恢复符合默认值。完整主程序 2394 项通过，0 失败、0 跳过；Release x64
构建 0 警告、0 错误，完整 format 检查 1404 个文件、0 处变更。
