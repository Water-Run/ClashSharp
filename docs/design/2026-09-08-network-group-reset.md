# 网络设置组的保留事务

代理组此前先修改页面的 TUN 和端口，再启动异步网络应用，随后逐项保存采样和
测试地址。失败或独占操作插入时，页面、存储与运行时可能分别停留在不同步骤。
透明代理组也没有让页面重置任务等待网络应用完成。

现在两个入口都等待与启动组、全量重置共用的保留事务。先排空已有运行时请求并
取得独占许可，再在一个已准入编辑器批次中写入所选组。代理组包含 TUN、混合端口、
采样开关与间隔，以及四个测试地址；透明代理组只包含 TUN。接口拒绝其他组、组合
作用域和普通许可，拒绝发生在创建事务文件之前。

默认值取自注册表元数据；TUN 默认值受页面已确认的服务能力限制，并与其他值在
同一批次中保存。完整目标快照记录这一决定，重放不需要重新解释服务能力。实际
网络应用继续由已有的网络事务验证，存储仍为 LocalSettings，没有引入第二个设置
写入来源，也没有改变数据包事务文件格式。

代理组协调采样和网络两个参与者，透明代理组只协调网络。失败时先回滚完整存储
快照，再补偿所有选中参与者；其中一个失败不会阻止另一个尝试恢复。补偿无法完成
时进入已有恢复状态并请求重启。持久写入开始后，页面取消不会中断应用或补偿。

页面任务等待事务结束后才发布整组字段，保留其他组的重启提示基线。透明代理组
保持混合端口、采样和测试地址；两组均不应用启动注册、语言或主题。旧同步重置
入口已由等待任务的接口替换，兼容作用域明确拒绝缺少保留事务能力的调用。

新增 37 项回归覆盖两组、服务可用与不可用、提交后取消、完整通知、采样或网络
失败与补偿失败、先前网络请求排空、真实存储适配器的整组提交与回滚、六项持久
阶段中断重放，以及不支持作用域和普通许可拒绝。运行时回调为模拟，中断测试
使用新的服务实例，不声明真实路由切换或系统断电测试。
