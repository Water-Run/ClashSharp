# 窗口位置、大小和最大化状态

本次补齐 G03 的保存与恢复路径，版本保持 `1.0.0.0`。窗口状态存储在应用本机数据目录的 `WindowState/v1/placement.json`，独立于可迁移的配置偏好和当前数据代际。普通配置导出不包含这个文件；清除全部本机数据会移除它。

窗口在内存中跟踪可见、非最小化状态。最大化保存此前的普通边界，最小化和隐藏到托盘保留上一次状态。启动后加载一次；如果加载期间用户已改变窗口位置，就保留用户的新位置。当前窗口已经最小化或隐藏时，恢复延后到重新显示，避免加载状态把它突然拉回前台。

恢复优先使用原显示器名称。显示器不存在时选择当前最近的可用显示器并居中；按有效 DPI 缩放普通尺寸和工作区内偏移，再限制到当前工作区。负坐标显示器和顶部任务栏使用物理屏幕坐标处理。显示器小于 800×600 DIP 时，原生最小跟踪尺寸以工作区为上限，使标题栏与操作仍可到达。

隐藏到托盘、正常退出及应用内重启前会保存完整状态。写入采用有大小限制的规范 JSON 和同目录原子替换。损坏文件或 I/O 失败进入应用诊断，不阻止启动或退出。窗口寿命管理初始化和保存任务；退出开始后停止接收新保存，等待已有任务完成。清除数据只排空任务，不保存，避免退出过程重新创建已清除的窗口状态。退出失败、窗口继续使用时重新开放保存。

实现使用项目固定 Windows App SDK 1.8 的稳定窗口接口。其内置 `PersistedStateId` 文档实际回退到 2.0 Experimental，因此没有为此引入实验 SDK。[Microsoft API 说明](https://learn.microsoft.com/en-us/windows/windows-app-sdk/api/winrt/microsoft.ui.windowing.appwindow.persistedstateid?view=windows-app-sdk-2.0-experimental)
