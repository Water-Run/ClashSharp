# 磁贴详情与菜单文字刷新

原实现会在点击磁贴或创建菜单时复制当前文字。随后 Agent 修改应用语言、运行状态更新或列表重新绑定，已打开的详情和排序菜单仍可能显示旧内容；托盘功能选择器也没有注册原位翻译回调。

本次修改：

- 磁贴详情改为控件持有的原生 Flyout，正文、目标链接和链接可见性使用单向绑定。段落继续去重并允许换行，链接文字支持换行，高度受窗口限制；打开时设置当前主题、语言和阅读方向。导航执行前重新读取当前命令。
- 托盘选择器原位更新标题、按钮、搜索提示、排序提示及已有选项文字。选项身份、业务载荷、勾选、草稿顺序和当前搜索输入均保留；重新测量翻译后的提示高度。
- 托盘排序菜单和触发器菜单绑定现有文字属性；多选行的无障碍名称、帮助及提示文字随选项更新。
- 页面／控件卸载关闭其临时浮层，列表容器回收关闭关联菜单。原窗口关闭栅栏阻止已销毁窗口的原生回调，临时菜单关闭不会取得或释放模态对话框租约。

保留 Windows 原生 Flyout／MenuFlyout，使用公开的附加浮层和 Presenter 样式接口；参见 [Microsoft Flyout 文档](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/dialogs-and-flyouts/flyouts)。
