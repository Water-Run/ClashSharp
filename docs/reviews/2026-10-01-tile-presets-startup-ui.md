# 磁贴预设、启动检查与主控对齐

本候选对应用户追加的三个要求：磁贴内置模板，启动提示的 WinUI 3 样式与交互，以及主控左右总高度一致。

磁贴编辑器提供日常使用、网络诊断、订阅管理和极简四个布局。日常使用沿用推荐布局；其余分别包括 18、11、6 个磁贴。模板先修改编辑器草稿，用户可继续调整；保存才通过现有布局权威提交，取消保留原布局。保存保留模板顺序和用户后续添加的项目，不增加第二个设置存储。手工调整后显示自定义布局，恢复推荐布局仍可使用。

启动检查使用原生 ContentDialog、InfoBar、ProgressRing、状态标签和链接入口。未添加订阅、未注册可选登录恢复不再使用与故障相同的警告表示；未知探测与实际代理残留仍明确提示。用户可重新检查，或从项目进入订阅和设置页。检查仍由展示所有者在后台收集，组件只展示已收集结果；关闭会取消并等待在途刷新，跳转在对话框关闭后进行。对话框跟随窗口调整滚动区域，保留键盘关闭和每次检查的错误记录。

主控左右共用同一 Grid 行。宽布局右侧四行按比例填满高度，模式按钮内容同步拉伸，和左侧状态卡片上下对齐；窄布局恢复自动行高与两列模式卡片。没有通过固定左侧高度截断内容。模板与启动检查文字覆盖现有八种语言。

包、程序集和文件版本递增至 `1.0.0.3`。
