# 安装选项与主程序风格统一

本轮按用户反馈优化安装器选项的层级和交互，沿用主程序设置页的平面设置行：左侧标题与说明，右侧开关或选择器。24 DIP 页面边距、14/12 DIP 正文层级、三组标题、直角细边框与原生 Fluent 深浅主题保持一致；开关、焦点与主操作使用同一套原生强调色资源。

原两栏复选框改为“快捷访问与启动”“网络与恢复”“初始偏好与集成”三组，底部操作固定，小窗口正文滚动。原生 CheckBox 只更换呈现模板，保留键盘、Toggle 自动化与既有可访问名称；说明作为辅助文本暴露。底部操作区域获得有限宽度，可在窄窗口换行，不把可取消或关闭操作挤出窗口。

通知名称统一为默认／仅重要／详细／关闭，并随选择解释失败、超时、成功及关闭策略。服务、系统预设和 MCP 说明反映当前选择；MCP 仍默认关闭、启用时只读。恢复推荐设置仅重置本次草稿，安装和账户确认期间保持冻结，不改变协议、默认值、现有用户偏好和维护路径。

本地 19 项目 Release/x64 构建零警告、零错误；安装器展示层 212 项通过。原蓝机使用生产 MainWindow 及合成运行端完成深浅主题、760×760／640×420、小窗口固定操作栏、绑定和原生 Toggle 检查；没有执行安装或读取真实配置。额外验证 150%／200%内容缩放模拟，没有更改系统 DPI。原生 WPF 资源检查通过，模型覆盖推荐恢复、冻结快照及四项通知说明。

预览与原始日志在忽略目录 `artifacts/verification/installer-style-20261101/`。生产候选的准确 CI、签名和交付身份待本轮完成后补入；预览不是实际安装通过声明。
