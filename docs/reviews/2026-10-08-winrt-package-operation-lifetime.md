## 寿命修正

`WindowsPackageManagerFacade` 原来直接等待临时 WinRT 操作的 `AsTask()`。实际使用的 WinRT.Runtime 为 `2.2.0.48161`，对应源码 `8649ee3eeb2445ca2a36d80d878ef60b96a6c65d`；其无取消令牌的 [Task 转换桥](https://github.com/microsoft/CsWinRT/blob/8649ee3eeb2445ca2a36d80d878ef60b96a6c65d/src/cswinrt/strings/additions/Windows.Foundation/Windows.Foundation.cs)不持有源操作对象。

新增 `WindowsPackageOperationLifetime`，在等待结束的 `finally` 中使用 `GC.KeepAlive`，使投影对象及其完成订阅一直存活到成功、错误或取消的原生终态。部署和卸载均使用该路径。已提交的 Windows 包操作继续等待其实际完成，没有改为提前取消、超时后报成功或轮询外部日志推定完成。

三项回归使用真实 Task 转换桥、弱引用和确定性的完整 GC，覆盖成功、错误与取消。旧写法三项均因源操作提前回收而失败；修正后全部通过，相关包适配器集合 25 项通过。服务器 Windows 集 1,320 项通过、零失败、零跳过，仍排除要求一次性环境的六项证书存储用例。原始 TRX 已取回独立核验；完整解决方案格式检查通过。
