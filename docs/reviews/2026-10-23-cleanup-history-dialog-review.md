# 日志清理与配置历史的显示、预览和确认

本轮从当前源码和已记录的实机场景检查剩余弹窗，而不是继续沿用笼统的“其他弹窗待验”。当前源码发现两个具体缺口：

- 配置历史仍从选中ComboBoxItem的Content取得文字控件。WinUI会把选中项的UIElement移至显示区并清空Content，因此历史选中项存在与此前磁贴模板相同的翻译遗漏。
- 日志清理弹窗未注册显示刷新：模式、筛选选项、参数说明和预览文字停留在打开时的语言。其容量目标还会在确认时再次用当前单位偏好换算，可能与预览时的字节数不同。

## 本次实现

`RetainedComboBoxOption`由应用持有文字控件和原始Tag，更新显示不经过可能被WinUI移空的Content，可访问名称绑定同一文字。配置历史沿用已读取的历史快照、选中版本和可恢复性；日志模式和筛选同样保留原选项对象。筛选选项的Tag仍是捕获时的查找键，翻译后的显示名称会处理冲突，不会扩大实际删除范围。

日志预览改为由当前视图模型拥有的只读结果，包含估计数量／大小和已经确定的条件。确认只接受这一结果，同一结果至多消费一次；其他页面的结果、重复确认以及取消后的确认不能造成清理。日期截止时间和容量字节数不在确认时重新计算。容量输入使用打开时捕获的单位规则，后续显示偏好变化不会重新解释输入数字。

弹窗翻译只更新标题、标签和预览的显示；不重新查询数据库，不重置模式、参数草稿或筛选。有效输入的显式编辑仍触发异步防抖预览；无效输入保持错误状态并禁用清理。预览数量文案明确为估计，因为读取后仍可能有新日志到达，实际删除仍按已确认的条件执行。

服务器在已接受b68源码基础上核对1,660个构建相关输入，再应用17个源文件。修改文件格式检查、完整Release/x64构建零警告／错误，相关 **550 / 0 / 0** 通过。新增六项测试覆盖不重复读取预览、单位变化不改变字节目标、译名冲突保留原筛选、外来／重复消费拒绝、取消不执行，以及格式快照保留单位规则和区域数字格式。原日期／数量边界、异步执行、错误报告及取消回归继续保留。本机没有产品或Sandbox执行。
