# 磁贴详情中的页面入口

蓝色服务器上的 `b20120e` 实际验收确认，信息磁贴可以展开完整详情并通过 Escape 返回原磁贴焦点，但没有进入关联页面的入口。德语最小窗口中“Abonnementverbrauch”还出现末尾一个字母单独换行。

本批保留信息磁贴的原有详情，在有明确关联页面时增加 WinUI 原生蓝色文字链接。配置、订阅、节点、规则、触发器、活动连接、系统日志、历史统计、关于及设置分别进入现有页面；历史连接数进入统计，活动连接数进入连接页。缺少导航能力时不显示空链接。现有开关和网络检查等操作仍执行原命令，没有改成页面跳转。德语订阅用量标题缩短为“Datenverbrauch”。

导航由页面装配注入，工厂把稳定目标解析为已有的类型化 ShellRoute；控件只展示信息和调用注入命令。点击链接先关闭浮层，只在磁贴仍加载且命令可执行时导航。链接使用现有八种语言的页面名称，不添加说明标语或自定义按钮样式。

十二项新增回归覆盖十类页面入口、未注入导航时不出现无效入口，以及保留原有命令和纯详情行为。测试实际加载 ViewModel 后执行独立的链接命令，核对请求目标及详情不变。首次测试夹具没有执行页面加载，导致尚未建立的磁贴无法查找；纠正夹具后验证通过，不把这轮失败记作产品缺陷复现。审计资源门禁也同步读取设置通知已经移入的 partial 文件，并检查逐观察者分发。

18 项目 Release x64 构建成功，29.37 秒、零警告、零错误；相关磁贴、顶部状态、布局、导航、架构、资源、本地化和统计加载回归 **291 项全部通过，零失败、零跳过**。测试项目在夹具和资源检查调整后重新构建成功，35.40 秒、零警告、零错误。证据在 `artifacts/verification/tile-navigation-20260930`，首次报告 `tile-navigation-regression.trx`、最终报告 `tile-navigation-final.trx`。新增控件公共成员的 XML 注释门禁已满足。

没有在开发机启动产品、安装器或修改产品和系统设置。此批需要在包含它的服务器候选安装包中复验链接、Tab/Enter、Escape、最小窗口与主题组合；不代表全部 68 个磁贴、设置整体代际切换或生产验收已经完成。
