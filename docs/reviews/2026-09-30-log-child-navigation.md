# 日志子页面的侧栏归属

蓝色服务器安装的 `b8b4201` 候选从首页系统日志磁贴进入日志后，侧栏仍选中首页。日志是子页面，原来的选择映射直接返回空项，没有表达其父级。

现在系统日志归属统计，带 `Trigger` 筛选的日志归属触发器。同步父级选择时，选中变化事件识别当前页面归属，避免再次导航到父页面并覆盖日志内容。用户主动点击已经选中的父项仍通过原生 ItemInvoked 返回父页面；返回历史保留完整路由和筛选参数。

新增五项回归覆盖默认日志、触发器日志、其他筛选，以及顶级页面保持自己的侧栏项。18 项目 Release x64 构建成功，30.46 秒，零警告、零错误；完整主程序 **3,553 项全部通过，零失败、零跳过**；完整 x64 格式检查退出码 0。首轮测试编译暴露测试公共方法使用内部枚举参数，已改用稳定标签，不计为产品缺陷。

本机仅进行编译和隔离测试，没有启动产品或安装器，也没有更改产品和系统设置。证据位于 `artifacts/verification/logs-parent-navigation-20260930`。本修正需要安装新服务器候选后验证内容不会被同步选择替换、父项点击和键盘操作、筛选以及返回历史；完整生产验收尚未完成。
