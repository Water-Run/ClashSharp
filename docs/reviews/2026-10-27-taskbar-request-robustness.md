# 安装后任务栏请求的收尾

最新状态：本修正已包含于8fd／9cfe候选，完整CI7466项、原生安装和任务栏首次说明／再次启动不重复的真实页面均通过。最新数据、签名和剩余磁贴手势范围见[2026-10-28整合原生验收](2026-10-28-integrated-native-acceptance.md)。以下保留最初实现阶段的记录。

继续审查发现：原实现先写“已处理”回执，再检查取消／前台状态，因此可能消耗尚未提交给 Windows 的请求。原回执写入后的删除也可能清掉安装器刚替换的新请求。不支持原生确认时则没有用户可见反馈。

现改用应用层的一次性协调器：查询期间取消或失去前台时保留请求；最终身份不匹配时不提交；同一窗口重复激活只保留一次执行。完成记录与请求身份关联，保留已处理的请求值作为标记，不在独立回执写入后删除它，因此并发替换的新请求可以继续被识别。已提交的确认不因取消观察而重复弹出。

Windows 原生边界区分已固定、可请求和不可用，优先检查是否已经固定。按[微软任务栏指南](https://learn.microsoft.com/en-us/windows/apps/develop/windows-integration/pin-to-taskbar)，原生返回 false 既可能是用户拒绝，也可能是系统不允许；不据此显示失败或反复请求。明确不可用时，显示可关闭的原生 InfoBar，给出“系统允许时可从任务栏图标菜单手动固定”的说明。关闭后不占用页面空间，语言变化不重新打开提示，八份语言目录均补齐。安装器说明相应改为“Windows 支持时请求确认”，开始菜单继续由 MSIX 管理。

新增26个行为用例：协调器17个、请求存储8个、信息栏视图模型1个，覆盖取消前后、失去前台、重复激活、用户拒绝、已有固定、平台不可用、过期身份及写回执期间的新请求替换。服务器独立源码副本基于 a98c3dc，最终21个变更源码在验证前后逐文件匹配；459项定向检查、206项安装器展示层测试及完整格式检查通过。两份原始TRX已下载核验，共 **665通过／0失败／0跳过**；中断恢复后服务器没有 dotnet、testhost、MSBuild 或 VBCSCompiler 进程。新源码的完整CI结果仍待核验，不沿用旧版7436项结果冒充本次通过。

本轮开发和测试通过 SSH 在原 Server 2025 进行，没有在本机执行产品。没有安装新包、发送真实任务栏固定请求或更改当前手验数据。已装手验候选仍为1813／8aac；本次不声称已完成新信息栏的实机视觉检查或原生固定确认，后续整合候选时还需针对这两项验收。用户手验、反馈修正和确认仍是正式发布前的独立节点。
