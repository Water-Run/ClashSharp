# 安装器软件包内容预检查

本轮继续[证书预检查检查点](2026-10-01-installer-certificate-preflight.md)，将主包与离线依赖包的同身份内容冲突检查接入认证 helper。新安装或维护在写入 Prepared 意图之前检查，真正准备服务前再次检查；发现冲突时不会先停止服务再等待 Windows 部署失败。包、程序集和文件版本递增为 `1.0.0.7`。

## 实现边界

`WindowsInstalledPackageFootprintCatalog` 使用需要管理员权限的整机 `PackageManager.FindPackages(packageFamilyName)`，覆盖其他用户已注册的同身份软件包，筛选准确的 PackageFullName。相同路径的重复结果合并；不同路径的多结果、错误身份、开发包或异常查询阻止继续。参见[微软整机包查询说明](https://learn.microsoft.com/en-us/uwp/api/windows.management.deployment.packagemanager.findpackages?view=winrt-26100)。

`WindowsPackageDeploymentPreflight` 分别检查主包和每个依赖。存在准确同身份包时，从已验证并锁定的候选读取 `AppxSignature.p7x` 和 `AppxBlockMap.xml`，与安装目录内文件的长度及 SHA-256 比较。没有准确同身份包时不读取其不存在的目录；不同版本的正常升级不要求内容一致。

读取器限制签名为 4 MiB、块图为 16 MiB，拒绝缺失、空内容、超限、重复及大小写歧义的归档条目。候选读取要求 Windows 载荷租约及准确文件条目。安装目录的普通祖先依次固定，拒绝重解析目录或文件；文件句柄阻止写入、替换，读取后重新核对目录身份。成功及失败路径均释放句柄。目录观察只申请读取属性，允许写入共享，阻止目录改名，不改变旧载荷锁的权限。

签名或块图不同返回 `installer.package.content_conflict`；无法核对内容或读取失败不计为通过。匹配结果仅允许继续原有 Windows 部署、签名、注册及最终状态验证，不替代它们，也不宣称两个文件证明任意 MSIX 的全部字节一致。参见[微软包签名说明](https://learn.microsoft.com/en-us/windows/msix/package/signing-package-overview)。外部 AppXSVC 在预检查后仍可能改变状态，实际部署失败继续由原持久事务处理，自动恢复此类竞态仍待完成。

已有恢复事务继续保留证据；已提交重放不新增安装预检查副作用。界面区分内容冲突的开始前阻止和开始后恢复，不把预检查描述成 Windows 已经执行部署拒绝，也不声称随意更换安装包能够恢复已开始的事务。

## 服务器只读验证

在 `WIN-07OBU2PV8C6` 上运行独立只读探针，最终采用与解决方案构建 SHA-256 一致的 `1.0.0.7` Windows 适配程序集。整机查询找到一个实际 `1.0.0.5` 注册包；读取器两次读取其受 Windows 管理的目录，与独立解析原归档 MSIX 一致：签名 1,556 字节，块图 463,700 字节。没有建立维护会话、安装更新、导入证书或修改产品设置。

标准 SFTP 连接关闭；后续标准输入传输未结束，确认远端未生成归档后终止该确切传输。改用既有 SSH 的 legacy SCP，核对归档和程序集 SHA-256 后执行成功。最终版本再次执行通过。应用 PID 860、服务 PID 16140、看门狗 PID 9756 保持，混合端口与活动 TUN 仍为空。旧探针 PID 已被系统复用，没有结束这个无关进程。

证据证明实际查询、读取权限及已知相同内容的比较可用，不代表新安装器的完整冲突、升级或恢复验收。认证 helper、受控冲突候选及产品恢复入口仍须签名包实测。
