# 页面与后台仓库入口：迁移开发节点

此节点延续首启仓库容器的私有迁移，尚未激活生产代际启动，也没有推送到 `main`。先前节点 `435ec7e` 已在独立工作目录重放到主线 `d1d23b79e1c6a90872e4778fdaa6e61e9d19d43a`，重放后基线为 `5a53a29a754c71298f6d6a059eeff8002b42cfcf`。主线的统计标签和规则命中改进已包含在本次构建中。

## 本次实现

- 页面组合、日志与统计适配器、配置与订阅管理、主控磁贴数据读取，以及采样、测速、规则命中和订阅更新适配器，改为依赖 `ILogStorage` / `IProfileCatalog` 操作接口。接口不暴露仓库释放权；旧导入所需的目录缓存失效保留为独立操作。
- `GenerationLogStorage`、`GenerationProfileCatalog` 每次调用都解析当前代的真实仓库，并保留整次同步或异步操作的代际许可。没有初始化、正在排空或者已经关闭时明确失败，不回退到旧目录。
- 管理器新增同步仓库操作和无返回值异步命令入口，覆盖实际 SQLite/文件访问。纯内存 `ReadSnapshot` 的边界保持不变。
- `GenerationTriggerTrafficContextSource` 将一批累计流量与滚动窗口查询固定在同一代。真实仓库容器提供该代的只读 SQLite 查询源，调用方无需缓存数据库路径。
- 实际页面和后台适配器已能接收上述入口。当前生产根仍将接口绑定到旧仓库，并保留旧静态工厂；只有完成设置、启动和数据事务整体切换后才能改为新入口。本节点不把接口替换当作生产切换完成。

## 验证

证据目录：`artifacts/verification/generation-consumer-cutover-20260930`。

新增 9 项回归全部通过，使用主程序程序集中的真实页面/后台适配器、真实配置仓库、SQLite、设置 JSON 和持久 manifest。验证包括：

1. 同一批页面与后台适配器在提交新代后读写新数据；旧配置、日志、节点延迟与规则命中不混入；重启后保留新数据；已返回的旧结果仍可读取。
2. 撤销候选后现有页面继续使用原仓库，候选仓库关闭。
3. 同步写入在输入枚举和 SQLite 提交结束前阻止排空完成；正常完成和输入异常均释放许可。
4. 页面导入固定仓库直到异步校验、配置文件和目录历史提交结束；关闭管理器不会中途释放依赖。
5. 导入失败、取消均不会发布半成品配置，也不会泄漏代际许可。
6. 排队等待共享写入锁的订阅结果提交仍受完整操作保护，重启后调度状态可核验。
7. 未初始化或已关闭的入口不会创建回退仓库。
