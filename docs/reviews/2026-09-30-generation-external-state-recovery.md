## 实现

每个运行实例现在拥有 `GenerationExternalStateRecovery`。在该代的独占修改许可下，它通过所属 UI 调度器读取实际语言、主题和强调色，通过 Windows 启动任务接口读取实际注册状态，并读取完整已验证网络状态。恢复快照包含数据代身份，不使用尚未应用的期望设置作为恢复目标，也不包含凭据。

恢复按照网络、启动注册、外观执行，并独立观察每类结果。回执丢失只有在实际状态与快照一致时才可视为完成。普通失败不会跳过其余类别；外观内部也会继续尝试语言、主题和强调色。第一次效果开始后使用不可取消的完成路径，避免页面取消留下半次补偿。恢复失败保留完整错误，不能报告成功。

网络补偿提供专门入口：另一目录接管后，原目录不必先把当前候选误认成自己的配置，便可重装捕获的原始目标。随后仍须核对配置、实际运行所有者和系统代理。失败补偿只允许在完整原目标被再次观察到时解除未解决状态，不接受无关候选的可用状态。

恢复入口验证所属设置会话仍然存活。不同数据代的快照，以及已退休仓库的恢复请求，均在开始效果前被拒绝。UI 调度器继续由该代外观参与者持有并清理，回调寿命与既有数据代操作相同。

## 后续接线
