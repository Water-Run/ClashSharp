# 主控页实际运行状态

上一节点的真实失败画面中，主控页同时显示“不可用”“可用”，且仍高亮未生效的接管目标。源码核对表明：模式高亮取自保存的 `CurrentMode`；“可用性”仅反映内核版本探测成功，二者均不足以证明实际网络状态。

本次主控页沿用 Agent 和连接页使用的 `INetworkStateObserver`，核对实际配置、控制器、内核归属与系统代理。读取在后台进行，限定两秒，并保留调用方取消语义。保存的目标值不会成为生效状态的替代来源，也不会因显示更新而被写回。

模式卡片与“当前模式”只呈现已核验结果；未确认时不高亮任何模式，状态显示“状态待确认”。旧“可用性”项目改为“运行状态”，与主标题采用同一状态来源，八种语言均已同步。切换失败或结果通知失败后，不假定此前状态已恢复，等待下一次独立观察。较早发出的异步读取也不能覆盖之后已完成的操作。

内核运行状态独立于版本探测结果；聚合统计不可读时仍不伪造零值。DNS 与内核归属只有在聚合观察和实际网络状态相符时才显示为当前数据。
