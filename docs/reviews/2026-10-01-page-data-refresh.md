# 数据切换后的页面刷新检查点

此检查点基于私有提交 `7a786eded8147e3878e703a7e7aa5a25402d00e9`，将配置、代理、日志、统计和连接页接入明确的数据目录变更通知。此前这些页面主要依赖导航加载或手动刷新，已经接受的旧请求和实时流可能晚于数据切换完成。

新增 `PageDataChangeSession` 管理页面可见期间的订阅。收到目录变更时立即撤销旧加载、修改操作及实时流的取消令牌，将页面标为失效，再调度受页面持有的刷新任务。刷新等待原操作完成后读取新目录；重复通知只执行最新刷新，旧页面访问的排队回调不能作用于重新打开后的访问。卸载取消刷新并释放订阅。取消回调失败会被单独记录，不跳过其他取消和刷新。

相关页面在失效期间拒绝发起新的修改操作。代理组、资源和连接行还会核对是否仍属于当前列表。配置刷新清除旧选择并替换行对象；代理刷新移除旧节点、组和资源；连接刷新清除旧控制器的行并重启实时订阅；日志刷新清除内存运行日志尾部并重新订阅。统计刷新先清空旧总量和各类行，避免新目录读取失败时仍显示旧目录统计。用户筛选条件继续保留。

配置页保留明确的等待顺序：先等待旧写操作结束，再等待数据切换刷新完成，最后开始本次导航加载。日志和连接的长连接由各自页面读会话持有，数据切换和卸载负责取消及等待，不与一次性刷新任务的短生命周期绑定。
