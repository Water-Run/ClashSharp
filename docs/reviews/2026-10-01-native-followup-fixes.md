# 原生验收发现的状态与升级文案修复

`1.0.0.1` 的[蓝色服务器验收](2026-10-01-dns-runtime-tiles.md)发现：内置直连配置在规则模式运行时，总览错误显示“节点不可用”；安装器成功从旧包升级，却仍将按钮和过程称为“修复”。DNS 服务器图标也使用了含义不合适的图书符号。

托盘与总览的运行快照现在带上同一份已验证配置的 profile identity。只有内置直连配置的规则模式明确显示 DIRECT；仍需完成真实控制器读取及前后配置身份比较。普通配置不借用不活动的 GLOBAL 选择，控制器失败、切换配置和取消不能推定为直连成功，DIRECT 也不借用历史延迟。

安装器根据经过校验的四段包版本进行数值比较：候选高于已安装版本时显示“更新”和“正在更新”，并列明两个版本；版本相同时继续显示“修复”。重新检查会刷新这一状态。该标记只影响说明文字，不增加操作权限：更新仍使用既有、受后端验证的维护事务。安装未就绪、没有安装、恢复中及仅允许卸载的状态不能借此暴露更新入口。

DNS 上游、备用和引导服务器统一使用网络图标。包版本、程序集版本和文件版本递增为 `1.0.0.2`，用于对已安装的 `1.0.0.1` 继续验证正常升级。
