# DNS 磁贴与递增包版本候选

总览增加 DNS 模式、DNS 监听、DNS IPv6、上游 DNS、备用 DNS和引导 DNS 六个信息磁贴，目录从 68 项增至 74 项。它们使用现有 WinUI 磁贴、详情和配置页导航，提供全部八种界面语言，保留用户原有布局；用户可在编辑器中搜索 DNS 并选择显示。

DNS 信息取自已验证的运行配置，包含 TUN 自动补入的 DNS。读取时对同一批文件字节计算 SHA-256，再解析激活计划和 DNS，避免摘要与显示内容来自两次不同读取。只有配置、快照、manifest、活动配置和内核运行归属相符时才提供 DNS 数据。停用、未知归属、切换配置和数据替换都会清除旧显示，不将未知列表显示为零。

模式、IPv6、监听和解析服务器的语义依据 [mihomo DNS 文档](https://wiki.metacubex.one/config/dns/)及[上游配置定义](https://github.com/MetaCubeX/mihomo/blob/Meta/config/config.go)。未声明的上游或引导服务器显示“内核默认”，不硬编码某个内核版本的默认地址。域名策略数量和是否遵循路由规则显示在模式详情；上游详情同时包含直连和节点域名解析服务器。服务器地址只显示端点，不泄露 URL 中的凭据、私有路径、查询或路由参数。这里显示已应用配置，不对解析服务器进行可达性或 DNS 泄漏探测。

全量回归发现新增不可变列表的默认引用比较会把相同运行配置误判为变化，触发现有代理恢复测试失败。DNS 值对象现按列表内容比较；真实配置服务的连续观察验证相等性，修改运行文件、快照或 manifest 则重新返回未知。原失败报告保留。

包版本、程序集版本和文件版本统一递增为 `1.0.0.1`，产品显示版本仍为 `1.0.0`。这允许从服务器已有 `1.0.0.0` 执行正常升级，避免把不同内容以同一包版本提交给 Windows。升级与新磁贴的原生结果必须绑定实际候选，不能由以下隔离回归推定。
