## 现有配置验收进度

现有配置的隔离副本为 445030 字节，包含 32 个节点、3 个策略组和 9035 条规则，没有代理提供器。直接调用当前程序的运行配置生成器，普通代理与 TUN 两种覆盖均通过其内置语义验证，并保留上述集合数量。私有输入及生成配置位于被 Git 忽略的验证目录，输出报告仅包含数量和结果。
