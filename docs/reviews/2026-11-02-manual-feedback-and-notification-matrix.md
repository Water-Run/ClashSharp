# 2026-11-02 手验反馈与通知覆盖清单

本轮接续用户安装、导入和界面手验，覆盖安装完成启动入口、安装选项、快捷方式与开始菜单图标、订阅名称、当前配置交互、地区旗帜、MCP 权限层级、固定概览、磁贴拖动及通知系统。保留蓝机本轮手验产生的数据，不使用此前已清理的历史备份。最终交付仍为 Setup.exe 位于第一层的完整解压目录。

## 通知级别

四种有效策略：总开关关闭、仅重要、默认、详细。关闭覆盖全部事件，包括故障和触发器。默认包含重要事件；详细包含默认及重要事件。Windows 自己的通知许可、免打扰和通知中心设置继续生效。

| 事件 | 关闭 | 仅重要 | 默认 | 详细 | 负责完成边界 |
| --- | --- | --- | --- | --- | --- |
| 内核运行中意外退出 | — | ✓ | ✓ | ✓ | 主窗口运行时观察；按故障边沿报告 |

“测试超时”属于默认级操作失败，不提升成整个代理不可用；“配置导入成功”属于详细级。当前配置和路由选择影响当前工作状态，成功属于默认级。常规设置与管理成功属于详细级。

同一次调用链通过多个装饰端口时共享完成回执；每次明确重试使用新作用域。专属网络故障通知登记异常所有权，外层仍记录诊断但不重复弹通用失败。通知传输故障不改变已经提交的业务结果，不替换原始业务异常。通知参数只接收应用撰写的资源和非秘密参数；不把订阅地址、令牌、配置正文或 MCP 凭据放进通知。

## 本轮实现

- 安装、修复完成后提供显式“启动 Clash#”，并提示后续重新运行完整目录中的 Setup.exe 管理程序。启动失败保留已安装状态并可重试。
- 快捷方式写入和移除后通知 Windows Shell 刷新。仍使用已注册包应用身份，不创建指向临时安装载荷的快捷方式。
- 从统一矢量源生成 46 个缩放和目标尺寸图标变体，加入实际打包项目；避免用带大量空白的小图放大。
- 订阅优先读取 profile-title，其次 Content-Disposition 文件名；支持 Unicode filename* 和 base64 标题。保留显式命名及用户重命名，失败和取消不提交新名称。
- 当前配置按钮展示切换中状态、阻止重复提交，当前行标记“当前使用”，成功说明配置变化和当前代理模式的关系。
- 离线旗帜覆盖 249 个 ISO 地区以及 EU、XK，名称覆盖八种界面语言；地区名称、常用城市、ISO 代码及旗帜识别保留明确边界。芬兰节点包含 FI 和中文名称的示例纳入回归。
- Agent 权限位于 MCP 服务器内的折叠子项，逐项复选，仍由用户独立授权并应用。
- 主控概览固定八项，旧的概览自定义记录不再影响加载显示；磁贴布局仍可单独编辑。
- 鼠标按下跨过移动阈值即可拖动磁贴；触控保留长按与滚动区分。取消、最小化、页面卸载仍撤销未完成顺序。
- 补齐 TUN、监听端口、订阅检查及统一设置动作的通知路径；网站测试保留逐项诊断，系统通知只报告批量汇总。

旗帜来源为 [flag-icons](https://github.com/lipis/flag-icons) 的固定提交，地区名称来自 [Unicode CLDR JSON](https://github.com/unicode-org/cldr-json) 固定提交；原始长度、SHA-256、来源地址保存在 eng/RegionAssets.sources.json，随包附许可证。Mihomo 维持已升级的 v1.19.33；本轮再查官方 latest API 与该版本相符。
