# 选择列表与托盘菜单原生交互

本轮在蓝色服务器 `WIN-07OBU2PV8C6` 的验收账户、182efc2 候选、德文深色普通窗口中发现以下问题。时间均为 UTC，开发机没有运行产品界面或改变产品设置。

| 场景 | 实机结果与修复 |
| --- | --- |
| 从搜索框按 Tab | 同一行依次停留在列表容器、操作按钮和装饰复选框；18:05:21 的第一次空格不改变选择。共享列表排除非操作容器和装饰复选框的 Tab 停留，保留行按钮的原生键盘行为 |
| 搜索与取消 | 无匹配显示本地化空状态，清空按钮恢复全部六项；修改草稿后 Esc 取消仍保留全部六项 |
| 仅保留安全退出 | 保存后显示一项，重新打开选择正确；18:09:28 的原生托盘菜单顶部存在无意义分隔线。分隔线改为仅在相邻功能组之间生成 |
| 取消最后一项并保存 | 18:11:02 无提示地恢复六项，违反草稿选择预期。编辑器增加“至少选择一项”提示，空选择时禁用保存，保留底层默认值兼容处理 |
| 列表文案 | 去除每行重复的托盘分类名；中英文、德文和法文计数改为适用于一项及多项的短文本 |

列表仍采用 WinUI 的行控件和原生焦点反馈，参考 [Microsoft 键盘交互](https://learn.microsoft.com/en-us/windows/apps/develop/input/keyboard-interactions)及[嵌套列表交互](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/nested-ui)。托盘菜单使用 Windows 原生菜单，当前产品提供功能显隐选择，菜单顺序固定；尚未实现拖动重排，不能把它计作测试通过。

取消勾选时曾观察到蓝色底色消失但深色勾形仍保留，重新打开后为空框。保留截图，后续区分控件动画、远程绘制与产品问题，不提前标为修复。
