# 固定源码材料生成与发行接入

为当前内置 mihomo `v1.19.27` 接入固定输入获取、确定性材料生成、独立归档验证和安装器发行目录晋升。Clash# 版本保持 `1.0.0.0`。最终生成归档已完成 Linux 离线编译复验；完整新 CI 与安装器重新打包正在接续，服务器仍运行此前已验收的 `a09d31d` 载荷。

## 输入与生成

`ClashSharp/Installer/source-materials.json` 将内置程序的 47,213,056 字节与摘要 `842fa17493a82c97148e76e3c523f5058e3cf386fba611cab86b6681e75f2f77` 绑定到源码提交 `5184081ac327394d9e15fa5d5f9f4a61e723fd94`、准确发布资产、原始源码/vendor/工具链及观察到的公开 CA 数据块。原始输入与既有离线编译证据见[固定源码材料记录](2026-10-06-mihomo-source-materials.md)。

新增获取脚本读取维护中的清单，只使用固定来源、长度及摘要；原始归档缓存不匹配时拒绝，下载先进入新临时文件，完整核验后才晋升。公开 CA 从已核验的内置程序固定区间提取，没有执行归档内容或导入证书。

源码材料生成器不下载输入，持有全部四份输入的只读句柄后流式生成 ZIP。归档采用固定条目顺序、时间和存储方式，包含原始源码、vendor、工具链、CA、GPL 原文、说明、离线编译脚本与绑定元数据，共八项。临时 ZIP 独立校验后才无覆盖晋升，现有输出保持；输入路径与祖先拒绝重解析点。

独立验证器将每个条目的长度与摘要同维护清单和支持文件比对，拒绝缺失/额外条目、重复或大小写碰撞、目录穿越、改变的脚本/许可、元数据来源和伪造的复现声明。它不执行或提取任何条目。

`BUILD-OFFLINE.py` 供 Linux x86_64、Python 3.12+ 使用。输入身份、规范文件集合和摘要全部验证后，使用 data 提取过滤器解开已固定的归档，替换公开 CA，禁用 Go 下载、限制两线程与十五分钟并交叉编译 Windows/amd64/v1。缓存和输出留在新 build 目录，既有目录保持；不运行 Windows 程序。权限恢复后，最终生成包已在 Linux x86_64、Python 3.13.5 上执行该脚本并编译成功。

## 打包接入

CI 离线输入阶段新增获取步骤，构建/测试阶段新增源码材料契约检查。安装器 build.ps1 生成 `MIHOMO-SOURCE-MATERIALS.zip`，在 payload-provenance.json 记录摘要、长度、对应源码提交和内置程序摘要；材料包复制到发行晋升目录后再次独立核验，并随完整 release 目录提供。

源码材料 ZIP 是发行资产。安装器运行所需的 EXE 与 payload 契约保持，材料不额外嵌入 MSIX。构建文档与内核通知已补齐取得/核验路径；GeoData 输入追溯与最终平台/签名验收仍保留。固定编译输入和一次离线交叉编译证据不声明上游程序逐字节复现。
