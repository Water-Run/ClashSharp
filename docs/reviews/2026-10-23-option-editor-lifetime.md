# 选择弹窗的语言、筛选与页面生命周期

磁贴编辑器及触发器条件／动作选择器此前只复制打开时的文字。托盘选择器虽能更新文字，非空查询却仍使用旧结果；筛选每次清空列表也会重建原本不需要变化的行。触发器选择器没有传递页面取消令牌，完成后直接修改打开时捕获的草稿。

本次把显示更新与业务草稿分开处理：

- `SearchableOptionFilter` 根据当前文字和查询，只移除、插入或移动真正变化的结果。结果相同时不发出集合变化；被过滤的选项保留原对象与勾选。各选择器完成一批翻译后重新筛选，查询文本保持。
- 磁贴编辑器原位更新说明、按钮、模板及现有选项文字。模板控制项不重建，模板的原有有序内容不随翻译改变；恢复推荐布局另起一行并支持换行，避免长语言挤压计数。
- 触发器选择器统一经过页面操作错误边界，并把页面取消、当前草稿替换或失效接入对话框生命周期。最终添加再次核对原草稿身份、可编辑状态及取消令牌；只修改当前未保存草稿。

## 选中项的文字控件归属

原因不是翻译资源缺失：[WinUI ComboBox的SetContentPresenter实现](https://github.com/microsoft/microsoft-ui-xaml/blob/main/dxaml/xcp/dxaml/lib/ComboBox_Partial.cpp#L978-L999)会把选中项的UIElement移至显示区，并将该项Content设为null。上一修正仍从item.Content取得TextBlock，因此恰好跳过选中项。现在由对话框单独持有各模板的文字控件引用，直接更新同一个TextBlock及其可访问名称绑定，不切换选择、不重建列表、不重新应用模板。

服务器对这一修订完成格式检查、完整Release/x64构建零警告／错误和 **412 / 0 / 0**。后续将再次核对收起和展开、三个语言与两个窗口尺寸；前两个失败候选的记录保留。测试辅助脚本的输出目录哈希和回退前置检查各有一次安装器启动前的失败，均在核对实际状态后修正，没有重放已启动的安装操作。
