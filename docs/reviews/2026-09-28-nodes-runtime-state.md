## 实现

- 控制端增加只读运行状态观察，沿用既有的应用进程及服务子进程归属规则。只有应用无内核且服务明确释放子进程归属，才返回停止；不访问控制端端口。服务状态只有 SCM 信息时继续获取可信 IPC 状态；未知归属、通信失败、双重归属和观察期间归属变化仍为失败，没有按异常消息屏蔽警告。
- 节点页确认停止后显示“内核未运行。启动后可查看策略组和资源。”，清空旧的运行时组及提供方，保留离线配置节点。提示覆盖八种语言；再次启动后刷新可以重新显示运行时内容。真实刷新失败继续显示错误状态并写警告。
- 原先三个工具栏按钮直接调用无页面取消令牌的命令。刷新节点、测速、刷新运行时现与初始加载、节点选择及提供方更新进入同一页面队列；同一工具栏动作重复点击合并，保持按钮可聚焦。离开页面撤销正在运行和排队的动作，下一次访问等待旧操作结束。
- 在应用测速和运行时读取结果之前再检查取消，防止后端迟到返回后覆盖已离开的页面。原有预期失败、调用者取消、内部取消和致命异常边界保持。
