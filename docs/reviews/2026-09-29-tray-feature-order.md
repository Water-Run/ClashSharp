# 托盘功能排序与原生菜单

设置已经保存托盘功能的枚举顺序，但编辑器始终按默认顺序展示，实际 Win32 菜单也按固定顺序生成。本轮补齐设置、编辑器和菜单之间的顺序传递。

- 编辑器先显示已有功能的保存顺序，再显示未启用功能；继续使用默认 WinUI 多选行、勾选框和焦点样式。
- 每行提供原生 `MenuFlyout` 的“上移／下移”。支持右键和系统上下文菜单键盘入口，首尾命令按实际位置禁用。功能提示提供八种语言，按换行后的实际高度缩减列表区域。
- 筛选时交换相邻可见选项，隐藏选项的位置与勾选状态保持；菜单关闭后焦点返回移动后的行。保存提交有序功能 ID，取消不写设置。
- 原生托盘菜单按保存顺序创建；相邻的设置与透明代理命令归为同组，其他区段分开，单项菜单无分隔线。未知 ID 和重复 ID 被过滤，全无有效功能时恢复默认菜单。

控件选择参照 [Microsoft 菜单与菜单浮出控件](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/menus)，使用系统提供的模板与主题颜色。
