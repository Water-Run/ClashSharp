## 已执行流程

- 安装器默认窗口、展开详情、最大化、点击安装、完成、重新检查、正常关闭。安装后账户包注册成功，产品服务运行，六处目录创建。
- 应用正常首次启动、启动引导、默认浅色、切换深色、最大化、主控与关于页面。
- 使用原生文件选择器导入本地配置，校验，设为当前，并在节点页读取运行时策略组。
- 待命模式下，真实 HTTP 和 SOCKS5 入站请求均直连，原生用户系统代理保持关闭。
- 按规则接管后，真实 HTTP 和 SOCKS5 入站请求均通过测试代理；在节点页将规则组切换为 DIRECT 后，实际请求立即直连。
- 持续传输在连接页显示目标、路径、规则和流量；统计页聚合配置、日期、节点数据；从统计页打开系统日志。

网络验收使用服务器回环地址上的受控 HTTP 源站和代理。代理仅允许自己的测试源站；同时支持 HTTP 转发及 CONNECT。最初只支持转发的夹具被 mihomo 的 CONNECT 请求拒绝，此阶段失败不归因于产品，修正夹具后重新验证并保存了新的结果。

## 第一批发现与修复

以下源码修复已加入本轮候选，目标服务器的新包复测尚未完成。

| 问题 | 修复与复测要求 |
| --- | --- |
| 系统代理界面显示开启，原生用户注册表仍为关闭 | MSIX 清单仅将当前用户 Internet Settings 键排除写入虚拟化；新包必须验证原生代理生效、退出恢复及卸载后无遗留 |
| 首页 SVG 只显示白色图形，缺少绿色底图 | 使用已有的高分辨率 PNG 标志；复测浅色、深色和缩放 |
| 应用深色、系统浅色时，原生窗口按钮黑色不可见 | 跟随实际 XAML 主题更新原生标题栏主题；复测切换、悬停及非活动状态 |
| 校验配置后选中项丢失，随即设为当前没有作用 | 配置及订阅按稳定 ID 恢复新行选择；无目标时禁用相关按钮；复测连续校验、应用、编辑、删除 |
| 当前配置显示内部 ID，磁贴换行后文字被裁切 | 运行时快照带回配置名称并核对 ID；磁贴单行省略并提供完整值提示 |
| 模式切换期间长时间没有忙碌反馈 | 显示进度并阻止并发模式切换；复测成功、失败、取消后的恢复 |
| 资源更新时间显示 0001 年 | 未报告有效时间时显示占位符 |
| 规则目标名称直接裁断 | 增加省略与完整内容提示 |
| 配置、订阅、规则列表高度无约束；节点页缺少整体滚动 | 列表分配剩余高度，节点页提供滚动并限制内嵌列表高度；需大量数据和较小窗口复测 |
| 安装完成后详情仍显示安装前状态 | 失效就绪快照时同时清空陈旧能力行；重新检查后显示最新结果 |

MSIX 注册表排除依据微软的 [Flexible virtualization 文档](https://learn.microsoft.com/en-us/windows/msix/desktop/flexible-virtualization)。原生标题栏主题使用微软的 [AppWindowTitleBar.PreferredTheme](https://learn.microsoft.com/en-us/windows/windows-app-sdk/api/winrt/microsoft.ui.windowing.appwindowtitlebar.preferredtheme?view=windows-app-sdk-1.8)。
