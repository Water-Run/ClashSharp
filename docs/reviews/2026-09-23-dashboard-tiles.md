# 首页磁贴扩充与专项验收

用户要求磁贴作为核心卖点，信息至少覆盖 Clash Verge 类客户端，且必须在目标 Windows Server 上验证实际功能、外观和交互。此项属于原有完整验收的追加范围；单元测试和源码检查不能替代实机通过。

## 对照范围

对照 [Clash Verge Rev 首页官方资源](https://github.com/clash-verge-rev/clash-verge-rev/blob/dev/src/locales/zh/home.json)中的九类首页卡片。核对日期：2026-09-23。实现保留 ClashSharp 的自定义磁贴及四种运行模式。

| 信息领域 | 对应实现与待验收内容 |
| --- | --- |
| 订阅与配置 | 活动配置名称、节点和规则数、订阅用量/额度、到期时间、最后更新、自动更新周期；本地配置、缺失元数据、零额度、无限期、过期和超额分别检查 |
| 当前代理 | 当前节点、延迟、模式；无节点、未测、成功、超时、失败和切换后的更新 |
| 网络设置 | 系统代理状态及实际地址、TUN 期望状态及生效状态、混合端口、内核运行归属 |
| 流量 | 上传/下载速度、最近 60 次采样趋势、活动连接数、本次会话累计、历史累计；停止/重启、短连接和采样间隔检查 |
| 网站检测 | 首页直接执行三个已配置目标，显示 HTTP 状态码、响应耗时、超时/连接失败；走当前 Windows 系统代理和 TUN 路由 |
| IP 信息 | 用户点击后通过当前网络查询 IP、地区、ASN、提供方、组织、时区、检测时间与来源；不自动请求第三方 |
| 内核信息 | 版本、内核进程内存、真实启动时间与持续运行时间、规则数量、运行归属及服务状态 |
| 系统信息 | 操作系统与架构、应用架构/版本、开机启动、启动/关闭行为、手动检查更新的结果与时间 |
| 定制与交互 | 推荐 20 张磁贴，保留已有自定义布局；选择、搜索、恢复推荐、取消、拖动、重启保存、完整详情和键盘操作 |

IP 查询使用 [ipwho.is 官方接口](https://ipwhois.io/documentation)，请求设置超时和响应体大小上限；只保留当前页面的检测结果。路由上下文变化会清除旧结果，进行中的旧请求不能回填到新上下文。它描述的是到该检测服务的实际出口，不把 TUN 下的普通请求错误称为强制直连。

内核进程内存来自已核实归属的应用子进程或服务监管子进程。[mihomo 的连接快照](https://github.com/MetaCubeX/mihomo/blob/Meta/tunnel/statistic/manager.go)包含缓存内存字段；为避免尚未刷新的缓存值，磁贴读取被监管进程的工作集。诊断字段可缺失，不改变内核归属判定。完整内核启动时间随服务连接快照传回，配置重载不应重置运行时间。

## 专项验收要求

1. 每一张可选磁贴：标题、图标、说明、数值来源、完整详情及其可用状态。无命令的磁贴支持鼠标、Tab/Enter/Space 展开可选中文本。
2. 四种模式以及应用/服务归属：数值与实际服务、进程、端口和系统代理一致；期望状态和当前状态不能混淆。
3. 动态数据：真实上下行、短连接、无流量、停止、重启、切换节点/配置、返回首页；趋势不跨长时间缺口连线，数值不会溢出。
4. 订阅：本地/内置配置、完整/部分/缺失元数据、零额度、无限期/过期、更新失败与重试；不凭空补零。
5. 网站/IP：未检测、进行中、成功、HTTP 错误、网络失败、超时、取消、再次执行、检测中离页或切换路由；失败不能继续显示上次成功结果。
6. 布局编辑：单选增减、隐藏全部、搜索无结果、恢复推荐后保存/取消、拖动排序、拖动不触发命令、重启保留、旧布局升级。
7. 显示：800×600、恢复窗口、最大化、浅/深/系统主题、七种语言与波斯语 RTL；长名称、长地址、长说明和大数值可查看完整内容。
8. 快捷操作：TUN、开机启动、采样等开关的忙碌反馈、失败恢复、重复点击；延迟、导入、导出与网络检测的取消和重试。
