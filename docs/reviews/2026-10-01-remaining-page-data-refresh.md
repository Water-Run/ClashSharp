# 订阅、规则与总览磁贴的数据切换检查点

此检查点基于私有提交 `84082516a7ffe0a46c621b208e18f08c3fdd9be6`。补上订阅链接页、规则页和总览页在数据目录替换后的刷新寿命，避免导入或重置完成后保留旧行、旧诊断和旧磁贴布局。

订阅与规则页面仅在可见时订阅目录变化。变化先撤销旧读取和排队操作，等待已经开始的任务收尾，再清除旧行并读取替换后的数据。读取还有独立修订检查，即使旧读取没有及时响应取消，也不能在新目录刷新后覆盖页面。新读取失败时保留空的安全状态，错误交给已有错误入口。

订阅行的有效性按对象身份检查，不能因为新旧目录中行的全部字段相同就接受旧对象。删除确认持有所确认的行，而不是在确认后重新读取可能变化的选择；编辑在进入对话框和确认提交时都核对当前行。取消后的结果不再留下旧成功文字或写入旧失败日志。

总览页在每次读取时核对数据目录身份，覆盖离开页面期间发生替换的情况。目录改变会清除旧运行汇总、流量历史、节点状态及诊断上下文，并重新读取磁贴布局和实际状态，绕过普通刷新限流。诊断上下文包含独立的数据修订，因此相同配置 ID 和相同路由也不会接受旧的公网 IP 或网站探测结果。

模式按钮与磁贴操作共用页面的任务所有者。数据失效期间，新点击和排队中的旧操作被拒绝；已接收任务必须收尾后才允许刷新。导入成功后，其旧输入令牌也会被目录变化撤销，因此完成刷新和结果对话框改由当前页面寿命继续持有。离开页面仍会取消提示，成功提示前会直接刷新已提交数据，避免等待自身对话框而互相阻塞。
