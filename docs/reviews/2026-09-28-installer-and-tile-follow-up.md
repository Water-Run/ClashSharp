## 实现

- 安装器使用一处产品标识、当前状态与说明、按需展开的详细信息，安装/修复/卸载/取消/关闭放在固定底栏。删除重复标题、产品卡、状态胶囊、“无需预装 .NET”和“安装器可直接运行”等冗余文案。保留账户切换、旧账户副本卸载确认与可复制诊断。
- 重新检查改为蓝色文本链接，状态主标题采用系统链接色；按钮使用系统原生悬停/按下/禁用/焦点渲染，删除自定义绿色按钮和紫灰背景。窗口默认 720×480，最小 640×420；正文可滚动，操作栏不随正文滚走。
- “当前模式”磁贴的说明随关闭、待命、规则、全局及未知/故障状态更新，沿用各语言已有文案。更新已有磁贴属性，避免为一次模式变化重建磁贴。

设计取舍参照微软[界面文案指南](https://learn.microsoft.com/en-us/windows/win32/uxguide/text-ui)中消除重复与按需显示详细说明的原则。该文档属于经典 Windows 指南，不将其旧版视觉示例视为 Windows 11 的外观认证。
