# 统计行标注与规则命中明细

蓝色服务器原生截图确认，配置、日期和节点明细直接显示几个数字，没有说明哪个是总量、上传、下载或记录数。规则区域也只显示聚合总数，缺少命中明细。

本批将统计存储行转换为不可变的展示行，明确标出总量、上传、下载；配置行使用连接数，日期行使用采样数，节点更新时间与日期按 Windows 区域格式显示。原始身份、字节数及时间保留在存储模型中，展示名称经过现有显示策略，不反写数据库。上传和下载使用同一可换行文本，避免最小窗口中两个窄列各自挤压。

接入已有的规则命中存储，显示命中最多的十条规则，按原始身份稳定打破并列；零命中记录正常显示，不当作没有数据。命中名称经过 UI 显示策略，不能影响排序或合并不同规则。新区域沿用现有 WinUI 卡片、ListView 和系统文字样式，八种语言各自编写标题、空态、总量及命中计数，不增加标语。

新增 **12 项**回归覆盖八种语言的实际资源、连接与采样标注区别、原始模型保留、零命中、数量上限、排序及显示过滤，以及规则读取或格式化失败时保留整份旧快照。空态遵循已有加载和错误边界；所有展示行在发布前准备，观察者不能看到混合的新旧数据。完整主程序 **3582 项通过，零失败、零跳过**，用时 2 分 31 秒；18 项目 Release x64 构建成功，57.21 秒，零警告、零错误；完整 x64 格式检查退出码 0。

本机只进行构建和隔离测试，没有运行产品或安装器界面，没有修改产品、系统或网络设置。报告与核验收据位于 `artifacts/verification/statistics-details-20260930/`。原生外观、实际数据库数据、刷新与滚动需要在包含本批代码的蓝色服务器安装候选上验收；源码测试通过不等于完整生产验收通过。
