# 已完成后台任务的严重异常观察

继续检查后台任务生命周期时，确认监督循环和触发器会在清理已完成任务时直接丢弃任务引用。任务若已因严重异常结束，随后调用启动、暂停或恢复可能返回成功，甚至开始新任务，导致原始严重异常被遗漏。

## 修正

两种任务的清理入口共同使用完成状态检查。普通可恢复故障继续遵循现有重试策略；完成任务中的严重异常必须先传播，任务引用继续保留，不能据此确认已暂停或开始新的任务。

另外，异步方法抛出的 `OperationCanceledException` 会令任务呈现为已取消，即使其内部包含严重异常；这种任务的 `Exception` 属性为空。因此检查同时观察取消任务的等待结果，保留其中的严重原因。单一原始失败保持对象身份，多个失败保持完整聚合结构。
