# 磁贴布局的可等待保存

2026 年 9 月 30 日将首页信息磁贴、顶部八个状态位和恢复默认布局接入可等待的设置修改入口。此前布局服务直接调用同步属性写入，拖拽结束事件没有等待或错误处理；界面已移动的顺序可能在保存失败后继续显示，直到重启才暴露未保存。

布局服务现在先复制、规范化输入，再通过 `AppSettingsService.ApplyChangesAsync` 提交对应规范键。普通修改许可一直持有到写入及通知结束，导入或重置持有独占许可时拒绝保存，取消发生在写入前时不改持久状态。此处仍使用现有唯一 LocalSettings 权威，没有同时激活 JSON 设置仓库。

页面将布局操作纳入已有的有序操作会话；顶部选项、显示项编辑及拖拽在保存期间禁用布局输入。禁用状态绑定在实际 WinUI `Control` 上，使用其系统外观和交互语义，见 [Microsoft Control.IsEnabled 文档](https://learn.microsoft.com/en-us/windows/windows-app-sdk/api/winrt/microsoft.ui.xaml.controls.control.isenabled?view=windows-app-sdk-1.8)。顶部选择的防重入范围覆盖完整异步操作，并在结束后重新绑定已提交的选择；恢复默认不会让绑定更新再次触发保存。

ViewModel 串行执行布局保存，连续修改顶部状态位时从最新已提交布局继续组合。信息磁贴的请求顺序在排队前复制，调用者之后修改输入不影响已接收请求。保存成功后才发布新的选择；普通失败会重新读取实际存储，明确保留错误。如果写入已成功、只是通知失败，界面显示真实的新值而不反向覆盖存储。原始写入和重读同时失败时保留两项异常；致命异常继续传播。

原生拖拽会先移动绑定集合。保存失败时恢复实际存储顺序；页面队列在执行写入前就取消时，事件结束路径恢复最后确认的顺序。成功且顺序已经一致时不清空、重建列表。可见性属性本身不再暗中触发同步保存。

新增 **24 项**回归：14 项覆盖布局等待、连续修改、失败、取消及恢复，2 项覆盖异步选择防重入，8 项通过真实布局服务与注入的独立值字典验证规范键、修改许可、通知和取消。相关磁贴、设置、页面操作寿命、资源及架构检查 **314 项全部通过，零失败、零跳过**。18 项目 Release x64 完整构建成功，用时 82.41 秒，零警告、零错误。

完整 x64 格式检查通过，退出码 0。报告、构建和格式记录位于 `artifacts/verification/tile-layout-async-20260930`；最终回归为 `tile-layout-final.trx`，`verification.json` 绑定十八个相关源码文件的散列及二十四项新增用例。首轮编译发现移除引用时遗漏了已有的 `Win32Exception` 使用，恢复命名空间引用后完成验证；这不是产品缺陷复现。

本批没有在开发机运行产品界面或修改系统设置，也没有争用另一项任务正在操作的服务器桌面。布局恢复、禁用外观、键盘焦点、拖拽和重新进入页面仍需在包含本批代码的新安装候选上复测。普通偏好与布局已有可等待入口；生产设置整体代际切换、全部磁贴使用场景和完整安装器验收仍未完成。
