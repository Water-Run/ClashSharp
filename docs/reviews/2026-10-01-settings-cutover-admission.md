# 设置权威切换与回滚恢复顺序

生产装配已统一使用 `GenerationSettingsAuthority`。设置、运行时设置、分组还原和显式恢复解析为同一个实例；根容器不公开物理设置仓库或代际会话。旧 `AppSettingsService` 在绑定前读取迁移输入，绑定后所有旧同步属性写入均拒绝，异步修改使用新的权威。此检查点替换原先无条件禁止生产接入 JSON 的临时检查，不跳过测试，也不以测试全绿代替完整发行验收。

## 本轮修复

回滚曾在后台生产者恢复前释放独占许可，普通设置命令可提前进入。确定性回归先复现 `Expected: Closing; Actual: Open`。现在在持有原数据目录和独占许可时恢复所有已暂停生产者，完成后再开放修改和执行发布。除了现有触发器、订阅和采样外，容器拥有的其他生产者也纳入暂停与恢复。

一旦开始暂停生产者，就等其返回明确的暂停状态后再处理调用者取消；未知暂停失败保留检查点并进入 RecoveryOnly，不能猜测原运行状态或重新接受普通修改。订阅循环在代际执行发布前等待，避免回滚过程中提前导入失败并错过首次更新。等待者取消互不影响，发布后再次暂停也使用新的等待信号。
