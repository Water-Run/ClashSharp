# 打开中的弹窗展示同步

上一轮仅刷新当前页面，原生弹窗仍在打开时复制主题、语言和阅读方向，并保留一次性生成的文字。Agent 修改显示设置时，页面与已打开的弹窗可能出现混排。

本轮在窗口级弹窗协调器的已准入生命周期内绑定根元素的语言、阅读方向和实际主题；结束、取消或显示失败时释放订阅。窗口开始关闭后，刷新回调与关闭回调共用存活限制，不再访问原生窗口。弹窗通过显式的显示回调更新已创建控件，输入、选择、探测快照和确认目标不随翻译重建。

首批接入范围：

- 订阅新增、编辑及删除：标题、操作、字段说明和已显示的校验错误；名称、地址、间隔和启用草稿保留。
- 配置重命名、删除及历史：保留名称草稿、原历史快照、选中版本和可恢复性，只重新格式化说明。
- 关于页代理信息：只重新格式化打开时的端口和路径快照，不重新探测。
- 设置的颜色选择、连接测试 URL 编辑及分组重置确认：保留颜色、URL 草稿、校验可见性及重置目标。
- 触发器删除和窗口关闭确认：保留原目录版本、目标与代理接管事实，不因语言变化重新获取或执行操作。

服务器独立源码目录 `dialog-live-presentation-20261020/source` 已核对 1,914 个输入文件；完整构建零警告、零错误，修改文件的产品和测试格式检查通过，相关 **364 项回归通过、零失败/跳过**。新增窗口关闭后的刷新隔离回归。准确 CI、签名安装与原生弹窗验收继续，当前安装仍为 `3350f37`。

启动检查与冲突修复内容、诊断进度、数据导入导出确认、清理范围和可搜索选项等尚未全部接入；这些内容需要保留各自的诊断事实、授权边界、筛选快照和排序，不能通过重建整个内容或重新执行检测来翻译。导航浮层、实际 Windows 11 与剩余显示/恢复矩阵继续待验，未将本轮计为全部界面完成。
