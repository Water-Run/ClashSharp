# 当前目录备份与导入、重置候选准备

此节点基于私有开发提交 `a151ed41093f2972ef944c39744d01768b6488b7`。主线仍为 `b70a1538ddd8e722abefa7635b909ffbbedf2b73`，没有新增命名分支；本轮复查开放 PR 为 0。**整体迁移尚未完成，此节点不是发布候选。**

## 已实现

设置页和主控共用的数据备份操作接入 `IDataPackageExporter`。导出协调器把实际持有的独占修改许可传给当前代导出器；设置来自一份不可变权威快照，配置文件来自该快照所属的目录，完整读取及目标文件发布期间一直持有此代。切换目录后，同一个导出入口自动读取新目录。普通许可、其他实例的许可以及覆盖应用数据目录的目标均被拒绝。

`DataPackageSettingsSnapshot` 只供既有 v1 格式序列化读取，不能改写任何设置。`ReadImportPlan` 沿用已有的有界 XML、文件数量、路径、文件内容及设置验证，返回已分离的导入内容；旧版的 `True/False` 会先转换成布尔类型，再进入规范化设置仓库，不因文字大小写被误拒绝。

`GenerationDataCandidatePreparer` 在独占许可和已排空的数据代切换下准备导入或全量设置重置。整包验证在分配候选目录之前完成。随后复制用户仓库、叠加包内文件、写入新设置仓库，并通过真实生产工厂打开配置目录、日志数据库和触发器数据库；整个文件及 SQLite 准备过程在调用者等待的后台任务内完成。它只返回未发布的候选，不改变当前 manifest，也不启动原生效果。

首次迁移和后续候选共用 `UserDataRepositorySnapshot`，复制范围继续限定为用户配置、历史、节点选择和相关数据库；使用 SQLite backup API 包含已提交的 WAL 页面，并检查副本完整性。已有数据代缺少主要仓库时不能悄悄初始化为空。生成的内核运行配置、设置应用证据和凭据不随文件复制。

`SettingsGenerationPlanner` 保留未提及的期望值和原有迁移历史，为新目录生成新的待应用身份，并将所有运行效果标记为尚未观察；不能把旧代的已验证效果当成新代的证明。全量设置重置恢复产品默认偏好，同时保留配置、订阅、日志和节点选择。

## 后续接入要求

导出已进入生产页面组合；**页面导入和重置仍使用旧事务入口，尚未改为调用新候选准备器**。需要完成以下连接后才能移除整体迁移门禁：

1. 在准备前暂停旧后台生产者，再排空目录操作；候选准备器自身不替代生产者暂停。
2. 将导入及全量重置的开始操作改为异步，并使用事务拥有的快照及运行入口。数据代排空时普通页面读取入口会拒绝访问，不能通过放开全局读取来绕过。
3. 候选激活需要明确的目录所有权。当前全局接管服务中的配置、节点选择及结算入口按“当前代”解析，不能直接用于未发布候选。启动初始化还包含 outbox 恢复和调度器启动，不能原样用于未提交候选。
4. 补齐 manifest 提交与原生效果之间的持久决策、失败补偿和重启恢复；补偿目标应来自之前实际验证的运行状态，不能把尚未应用的期望值当成原状。
5. 完成分组重置、终端数据清理、页面快照通知和触发器编辑版本冲突处理，再合并主线并在蓝色 Windows Server 验收完整功能、磁贴、样式和安装器。

本轮没有在本机运行产品界面或安装器、没有修改系统代理，也没有向蓝色服务器部署这一私有迁移节点。
