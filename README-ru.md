Clash# — нативный прокси-клиент для Windows на ядре [mihomo](https://github.com/MetaCubeX/mihomo). Приложение написано на C# с использованием .NET 10 и WinUI 3 и распространяется в виде пакета MSIX; установку, восстановление и удаление выполняет отдельный установщик на WPF. Поддерживаемые системы: Windows 11 x64 и Windows Server 2025 с возможностями рабочего стола.

Помимо управления подписками, профилями, узлами и правилами, Clash# решает ряд задач, специфичных для Windows: перехват и восстановление системного прокси, прозрачный прокси (TUN) для всего компьютера, доступ к прокси для WSL, терминалов и приложений Microsoft Store, а также настройки прокси, оставшиеся после аварийного завершения.

## Возможности

| Область | Описание |
| :--- | :--- |
| **Интерфейс** | Нативные элементы управления WinUI 3, значки Fluent и материалы Windows 11; поддерживаются светлая и тёмная темы и системный цвет акцента. Страница «Управление» построена из плиток; плитки можно показывать, скрывать и переупорядочивать. |
| **Проверки при запуске** | Перед запуском прокси проверяются внешние процессы mihomo, занятые порты, ручной прокси Windows и другие адаптеры TUN/VPN; для пунктов, которые можно обработать безопасно, предлагается исправление. |
| **Восстановление прокси** | Системный прокси восстанавливается при выходе; при аварийном завершении — немедленно, процессом восстановления; при запуске остаточные настройки прокси проверяются и удаляются. |
| **Сетевые исправления Windows** | Доступ к прокси для WSL, терминалов и Microsoft Store диагностируется по отдельности; исправления применяются и откатываются для каждого пункта. |
| **Триггеры** | При выполнении всех условий заданные действия выполняются по порядку. Условия: трафик, скорость, число соединений, время работы, системное время; действия: смена режима, разрыв соединений, отправка уведомлений, выход из программы. |
| **Статистика и журналы** | Записи о трафике, соединениях, состоянии узлов и срабатываниях правил хранятся в локальной базе данных SQLite. |
| **Языки интерфейса** | 简体中文, 繁體中文, English, 한국어, Русский, Français, Deutsch, فارسی (раскладка справа налево). |

## Режимы

Режимы Clash# названы по их действию на сеть. Соответствие общепринятым названиям:

| Clash# | Общепринятое название | Поведение |
| :--- | :--- | :--- |
| **Отключено** | Выкл. | Ядро останавливается, системный прокси восстанавливается. |
| **Ожидание** | Напрямую | Ядро работает, трафик по умолчанию идёт напрямую. |
| **По правилам** | Правила | Трафик распределяется по правилам профиля. |
| **Полный перехват** | Глобальный | Весь трафик идёт через выбранный прокси. |

Прозрачный прокси (TUN) управляется параметром «Прозрачный прокси» в разделе **Настройки › Прокси** и по умолчанию включён. Если он включён и служба Mihomo доступна, перехват выполняется через TUN и распространяется также на программы, не использующие системный прокси. Если служба Mihomo не развёрнута, перехват выполняется через системный прокси Windows.

> [!CAUTION]
> Прозрачный прокси перехватывает маршрутизацию и DNS всего компьютера. Clash# рассчитан на один компьютер с одним интерактивным пользователем и не изолирует трафик между пользовательскими сеансами.

При включённом параметре «Включить цветовой индикатор состояния в трее» в разделе **Настройки › Панель задач и трей** значок в трее обозначает текущее состояние цветом:

| <img src="./ClashSharp/ClashSharp/Assets/Tray/Logo.Inactive.svg" width="24" alt="Серый значок" /> | <img src="./ClashSharp/ClashSharp/Assets/Tray/Logo.SystemProxy.svg" width="24" alt="Зелёный значок" /> | <img src="./ClashSharp/ClashSharp/Assets/Tray/Logo.Tun.svg" width="24" alt="Фиолетовый значок" /> |
| :---: | :---: | :---: |
| Отключено или Ожидание | Системный прокси | Прозрачный прокси |

## Установка

**Системные требования:** Windows 11 x64 или Windows Server 2025 с возможностями рабочего стола.

После выхода официальной версии пакеты публикуются на странице [Releases](https://github.com/Water-Run/ClashSharp/releases).

1. Пакет выпуска скачивается и распаковывается. `ClashSharp-Installer.exe` должен находиться рядом с папкой `payload`.
2. `ClashSharp-Installer.exe` запускается в текущем сеансе пользователя. Приложение устанавливается для пользователя, запустившего установщик; запуск от имени администратора и предварительная установка .NET не требуются.
3. При развёртывании службы Mihomo и необходимого доверия к сертификатам установщик запрашивает подтверждение администратора. Перед подтверждением следует проверить отображаемого издателя.

Восстановление, обновление и удаление выполняются повторным запуском того же установщика.

> [!WARNING]
> Удаление следует выполнять через `ClashSharp-Installer.exe`. При удалении только через «Параметры › Приложения» Windows ресурсы уровня компьютера, в том числе служба Mihomo, не удаляются.

## Начало работы

1. В разделе **Прокси › Ссылки** добавляется ссылка на подписку. Clash# загружает и проверяет соответствующий профиль.
2. В разделе **Прокси › Профили** проверяется, что этот профиль является текущим.
3. На странице **Управление** выбирается режим **По правилам**.
4. В разделе **Прокси › Узлы** выбирается узел; предварительно можно выполнить проверку задержки.

При каждом запуске Clash# показывает руководство, сводящее результаты проверок подписки, службы прозрачного прокси, восстановления при запуске и остаточных настроек прокси. Руководство отключается в разделе **Настройки › Запуск**.

Локальный смешанный порт по умолчанию — `10000`; он обслуживает HTTP и SOCKS. Программы, не использующие системный прокси, могут обращаться к `127.0.0.1:10000` напрямую. Порт изменяется в разделе **Настройки › Прокси**.

При закрытии главного окна Clash# по умолчанию сворачивается в трей и продолжает работу. Для выхода предназначен пункт «Безопасный выход» в меню трея; при выходе по умолчанию ядро останавливается, а системный прокси восстанавливается.

### Страницы

| Страница | Назначение |
| :--- | :--- |
| **Управление** | Переключение режимов; плитки показывают состояние ядра, скорость, трафик, задержку, расход подписки, внешний IP и другие сведения. |
| **Прокси** | Узлы, профили (с историей версий), ссылки на подписки и правила. |
| **Триггеры** | Задачи автоматизации, проверяемые сверху вниз. |
| **Соединения** | Активные соединения с процессом, сработавшим правилом и маршрутом прокси. |
| **Статистика** | Долгосрочные итоги по профилям, узлам и времени; отсюда же открываются системные журналы. |
| **Настройки** | Язык и оформление, запуск, прокси, исправления Windows, уведомления, трей и резервное копирование данных. |

## Частые вопросы

<details>
<summary><b>WSL, терминал или приложение Microsoft Store не получают доступ к сети через прокси</b></summary>
<br />

Эти программы не используют системный прокси Windows. В разделе **Настройки › Windows** для каждой из них выполняется диагностика и по её результату применяется исправление; исправление можно откатить в любой момент. При включённом прозрачном прокси трафик таких программ также перехватывается.
</details>

<details>
<summary><b>При запуске сообщается о конфликте</b></summary>
<br />

Проверка конфликтов охватывает четыре случая: внешний процесс mihomo, занятый порт прокси, включённый ручной прокси Windows и другие адаптеры TUN или VPN. Диалог поясняет каждый пункт и предлагает исправление там, где его можно применить безопасно. Об адаптерах TUN и VPN только сообщается; Clash# их не отключает. Проверку можно повторить в любой момент в разделе **Настройки › Запуск**.
</details>

<details>
<summary><b>После аварийного завершения системный прокси остаётся включённым</b></summary>
<br />

При аварийном завершении Clash# процесс восстановления немедленно возвращает системный прокси, всё ещё принадлежащий Clash#. Если компьютер был выключен раньше, Clash# проверяет и удаляет остаточную настройку при следующем запуске. Кроме того, в разделе **Настройки › Запуск** можно зарегистрировать «Резервное восстановление при запуске», чтобы та же очистка выполнялась при входе в Windows, не дожидаясь запуска Clash#.
</details>

<details>
<summary><b>Названия или флаги регионов отличаются от профиля</b></summary>
<br />

**Настройки › Функции материкового Китая** по умолчанию включают замену флагов и дополнение текста, изменяя в интерфейсе названия и флаги некоторых регионов в соответствии с нормами материкового Китая. Функция влияет только на отображение; профили, журналы, поиск, скопированный текст и экспортированные данные не изменяются. Отключается в том же разделе.
</details>

<details>
<summary><b>Резервное копирование и обновления</b></summary>
<br />

В разделе **Настройки › Данные** настройки Clash# экспортируются в один файл, при необходимости вместе с конфигурацией прокси и подписками, для последующего импорта. Журналы экспортируются отдельно в виде базы данных SQLite; их импорт не поддерживается.

Страница **О программе** проверяет наличие новых версий на GitHub Releases. Обновления устанавливаются установщиком.
</details>

## Сборка из исходного кода

Для сборки требуются Windows x64, PowerShell 7 и .NET SDK версии, указанной в [`global.json`](./global.json).

```powershell
dotnet restore ClashSharp/ClashSharp.slnx --locked-mode
dotnet build   ClashSharp/ClashSharp.slnx -c Release -p:Platform=x64 --no-restore
dotnet test    ClashSharp/ClashSharp.Tests/ClashSharp.Tests.csproj -c Release -p:Platform=x64 --no-build
```

Сборка установочного пакета описана в [Installer/README.md](./ClashSharp/Installer/README.md) (на китайском языке).
